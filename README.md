# Secure Cloud Deployment using Terraform

## Overview

This repository contains a beginner-level DevOps and Cloud Computing project developed using Terraform.

The project demonstrates the concept of Infrastructure as Code (IaC) by automating local resource creation through Terraform configuration files.

## Objectives

* Understand Infrastructure as Code (IaC)
* Learn the basics of Terraform
* Explore automation using configuration files
* Gain hands-on experience with DevOps workflows

## Technologies

* Terraform
* Git and GitHub
* macOS Terminal

## Repository Structure

* main.tf: Defines the local resource configuration
* provider.tf: Configures the Terraform provider
* outputs.tf: Defines output values
* README.md: Project documentation
* project.txt: File generated automatically using Terraform

## Implementation

The project uses Terraform to automatically create a local file named `project.txt` containing project-related information.

## Terraform Commands Used

```bash id="5q6r4v"
terraform init
terraform plan
terraform apply
```

## Execution

The Terraform configuration was executed successfully in a local environment. On running the Terraform workflow, the project automatically generated the `project.txt` resource based on the configuration defined in the Terraform files.
